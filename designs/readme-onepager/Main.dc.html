Eudaimonia

A transparent, consumer-facing donation platform on Base L2. Donors pay with a credit card; the money is converted to USDC on-chain, routed through an auditable smart contract, and delivered to vetted charities via Endaoment. Every gift produces a public, verifiable receipt that traces the money from donor to charity.

From the Greek εὐδαιμονία (eudaimonia): human flourishing, the good life.

Base L2 USDC Endaoment 1% fee — hardcoded

How it works

Select
The donor picks a curated, urgent cause on the landing page.
Pay
Card or Apple Pay at /donate/[campaignId] — no wallet, no crypto knowledge required.
On-ramp
Stripe Crypto Onramp converts the fiat to USDC on Base; /processing/[sessionId] tracks settlement.
Route
The TransparentDonationRouter pulls the USDC, skims the hardcoded 1% platform fee to the treasury, and forwards 99% to the charity's Endaoment org Entity.
Prove
/receipt/[txid] decodes the on-chain DonationRouted event into a visual timeline with real transaction IDs.
Where the money goes
For every $100.00 donated
$99.00
forwarded directly to the charity's Endaoment org Entity
$1.00
platform fee to the treasury — FEE_BPS = 100, a compile-time constant
Fiat in, USDC out: Stripe Crypto Onramp → TransparentDonationRouter → Endaoment → charity.

Trust model

The routing contract is deliberately small and rigid — the guarantees live in the bytecode, not in policy.

The fee is hardcoded
FEE_BPS = 100 (1%) is a compile-time constant. No owner can raise it.
USDC and treasury are immutable
Set once at deploy, validated against the zero address, unchangeable afterward.
Destinations are allowlisted
donate only forwards to owner-vetted Endaoment entities, so a valid DonationRouted log can never point at an attacker-controlled address. The owner key must be a multisig in production.
Guarded transfer path
Checks-effects-interactions plus ReentrancyGuard on the donation path, with OpenZeppelin SafeERC20 for transfers.
contracts/src/TransparentDonationRouter.sol
/// Solidity 0.8.24 · Foundry · OpenZeppelin
uint256  public constant  FEE_BPS = 100;        // 1%, no owner can change it
IERC20   public immutable usdc;                 // fixed at deploy
address  public immutable treasury;             // fixed at deploy
mapping(address => bool) public allowedOrgs;   // owner-vetted Endaoment entities

Getting started

Prerequisites: Node.js 20+, npm, and Foundry for contract work.

App — Next.js
$ git clone https://github.com/mnkprs/Philotimo
$ npm ci
$ cp .env.local.example .env.local
  # Stripe keys, KV, RPC URLs, addresses
$ npm run dev
Contracts — Foundry
$ cd contracts
  # vendor forge-std + openzeppelin → lib/
$ forge build
$ forge test
  # fork tests self-skip without BASE_RPC_URL

Defaults target Base Sepolia; public RPC endpoints work for development. Deployment to Base Sepolia or mainnet is an operator action — see contracts/DEPLOY.md.

Testing

Developed test-first (TDD) with an 80% coverage floor. CI runs two independent jobs on every PR — the frontend pipeline and the contracts pipeline.

npm test npm run test:coverage npm run test:e2e npm run test:a11y:lighthouse forge test npx tsc --noEmit
